1. VPS Requirements:
   • OS: Ubuntu 20.04 / 22.04 LTS
   • RAM: 2GB minimum (4GB recommended)
   • Storage: 20GB minimum
   • CPU: 2 Core

2. Software yang Dibutuhkan:
   • Node.js 20.x
   • PM2 (Process Manager)
   • Chromium Browser
   • Git (optional)

═══════════════════════════════════════════════════════════════
🎯 QUICK DEPLOY (5 MENIT)
═══════════════════════════════════════════════════════════════

STEP 1: Setup VPS (Sekali saja)
────────────────────────────────────────────────────────────────
ssh root@YOUR_VPS_IP

# Install Node.js 20.x
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs

# Install PM2
npm install -g pm2

# Install Chromium
apt install -y chromium-browser ca-certificates fonts-liberation \
    libappindicator3-1 libasound2 libatk-bridge2.0-0 libatk1.0-0 \
    libcups2 libdbus-1-3 libgdk-pixbuf2.0-0 libnspr4 libnss3 \
    libx11-xcb1 libxcomposite1 libxdamage1 libxrandr2 xdg-utils \
    libgbm1 libxshmfence1

# Setup PM2 startup
pm2 startup

STEP 2: Upload Bot
────────────────────────────────────────────────────────────────
# Di komputer lokal
chmod +x deploy-to-vps.sh
./deploy-to-vps.sh YOUR_VPS_IP

STEP 3: Setup Environment
────────────────────────────────────────────────────────────────
# Di VPS
cd /home/bot-whatsapp
nano .env

# Isi minimal:
GEMINI_API_KEY=AIzaSyCaq1aKirCU_OU3tr-60BWRotT81zSo8vk

# Save: Ctrl+X, Y, Enter

STEP 4: Start Bot
────────────────────────────────────────────────────────────────
pm2 start ecosystem.config.js
pm2 logs wa-bot

STEP 5: Scan QR Code
────────────────────────────────────────────────────────────────
# Lihat QR di logs atau download:
scp root@YOUR_VPS_IP:/home/bot-whatsapp/qr_code_bot-wa-saya.png ./

STEP 6: Save Configuration
────────────────────────────────────────────────────────────────
pm2 save

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Bot tidak start?
→ pm2 logs wa-bot --lines 50

Chromium error?
→ apt install -y chromium-browser
→ pm2 restart wa-bot

Memory error?
→ Edit ecosystem.config.js
→ Ubah max_memory_restart: '2G'
→ pm2 restart wa-bot

QR tidak muncul?
→ ls -la qr_code_*.png
→ pm2 logs wa-bot | grep QR
